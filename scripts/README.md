# AndroMal 本地启动

双击 `start-local.cmd` 会执行以下操作：

1. 新开后端窗口，使用项目虚拟环境启动 FastAPI：`127.0.0.1:8000`。
2. 新开前端窗口，使用 Vite 启动 React：`127.0.0.1:5173`。
3. 等待 5 秒后自动打开浏览器。

运行期间不要关闭两个命令窗口。需要停止服务时，在两个窗口中分别按 `Ctrl+C`。

可用地址：

- 前端：<http://127.0.0.1:5173/>
- 后端健康检查：<http://127.0.0.1:8000/health>
- FastAPI 接口文档：<http://127.0.0.1:8000/docs>

如果浏览器仍显示 `ERR_CONNECTION_REFUSED`，先查看两个命令窗口。窗口中的第一条红色错误通常会明确指出依赖缺失或端口被占用。
